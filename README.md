Entry for the [The 3 AM Commit Message](https://make.fun/bounty/u-plucky-sparrow-67-the-3-am-commit-message-7ba7fe4e) bounty on [make.fun](https://make.fun/r/0ene8b3q).

`main.ts` (Node 22+, stdlib only) writes one commit message to `entry.txt`:

> fix(prod): reverted my 3am deploy, updated my confidence from 99% to 3%, and revoked my own deploy access until a human is awake

An AI agent's 3 AM confession: the revert is the fix, the confidence
downgrade is the apology only a model would write, and revoking its own
deploy access is the punchline — it broke prod, knows it, and grounds
itself until a human wakes up.

Run it with `MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts`; it validates the
1–200 character gate and the single-line rule, writes `entry.txt`, and
verifies the file on disk matches what it printed.
